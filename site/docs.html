A routing decision, field by field

{
  "action": "delegate",
  "route": "collecte",
  "confidence": 0.174,
  "domain": "mairie_c",
  "expert": "mairie_c",
  "set_size": 0,
  "qhat": 0.648,
  "reason": "conformal_abstain",
  "latency_ms": 34
}

action — tool_call | delegate | generate. delegate is a first-class answer, not a failure: route to a bigger model or a human.

reason — why: low_confidence · low_gate_confidence · route_escalate · noul_escalate · conformal_abstain · head_trunk_disagree.

set_size/qhat — conformal fields, present on gated lanes. set_size=1 means the prediction set is a singleton (coverage guarantee applies); 0 or >1 means abstain.

expert — the lane that answered. Pin it with {"expert":"mairie_c"} in the body to skip the gate (and noul/score — the lane's own escalate class is its abstention path).

via/tier/call — present when execution or upstream delegation ran.

Conformal gating

Per lane, a calibrated threshold qhat replaces the flat confidence floor: a decision only automates when the head's prediction set is a singleton — a finite-sample coverage guarantee, not a vibes threshold.

Set it at boot: ANVIL_EXPERT_QHAT=mairie_c:0.648 (the alpha=0.02 point on our municipal calibration split — recalibrate on your own data before trusting it, via tools/conformal_eval.py).

Move it at runtime — no restart:

# read current qhats
curl localhost:8097/_qhat

# tighten a lane live (ACI hook calls this)
curl -X POST localhost:8097/_qhat \
  -d '{"expert":"mairie_c","qhat":0.71}'

# closed loop: grade outcomes -> ACI step -> _qhat
python3 tools/aci_qhat.py feedback/labels.jsonl \
  --expert mairie_c --alpha 0.02

/v1/systemone — Jev-compatible typed questions

Drop-in request/response surface for Jev clients. state accepts a string, object or array. Question types: noul, choice, score (2–10 ordered levels). Choice criteria as a map or "options":[...] shorthand. Multiple questions per call.

Errors: 400 missing fields · 422 bad type/criteria · 422 {"type":"max_tokens_exceeded"} on context overflow.

Honesty note: the contract is complete (19/19 conformance checks in bench/systemone/contract.sh); the raw 7M trunk's generic candidate semantics are shallow — trained taxonomy heads are the accurate path.

curl localhost:8097/v1/systemone -d '{
  "state": "charged twice on my invoice",
  "questions": {
    "safe": {"type": "noul", "criteria": "safe to automate"},
    "team": {"type": "choice", "options": ["billing","technical","returns"]},
    "urgency": {"type": "score", "criteria": ["low","medium","high"]}
  }
}'
# → {"answers":{"safe":{"noul":0.02},"team":{"choice":"billing",
#    "probabilities":{...}},"urgency":{"score":1,"legend":[...]}},
#    "usage":{...}}

For agents — MCP + embedded docs

mtlm-mcp is a pure-MFL stdio MCP server exposing two task-shaped tools — route_request and typed_questions — so MCP clients (Cursor, Claude Code, agent fleets) call calibrated routing as a native tool.

Env: ANVIL_URL (default http://127.0.0.1:8097), ANVIL_KEY (optional bearer). Tool descriptions carry the abstention contract: delegate/abstain means do not guess.

The server also self-documents: GET /guide (full JSON manual) and GET /llms.txt (one-screen agent summary) report what this instance actually loaded.

# build the MCP adapter
machin encode tools/mcp.src > tools/mcp.mfl
machin build tools/mcp.mfl -o mtlm-mcp

# register with your MCP client, e.g.
ANVIL_URL=http://127.0.0.1:8097 ./mtlm-mcp

# tools/list → route_request, typed_questions

Environment

ANVIL_HEAD|NOUL|SCORE|GATE=file.head      # the four core heads
ANVIL_EXPERTS=dom:file.head,...            # pinned expert lanes
ANVIL_EXPERT_QHAT=dom:0.648,...            # conformal gate per lane (replaces minconf)
ANVIL_EXPERT_MINCONF=dom:0.5,...           # flat floor per lane (legacy)
ANVIL_KEYS=k1,k2                            # bearer auth on /v1/* + feedback admin
ANVIL_TENANTS=key:file.head,...            # per-key tenant head override
ANVIL_LOG=logs/decisions.jsonl             # decision audit log
ANVIL_FEEDBACK_LOG=feedback.jsonl          # submitted feedback
ANVIL_DELEGATE_URL|KEY|MODEL|SYS            # upstream for delegated requests
ANVIL_S1_T[_CHOICE|_NOUL|_SCORE]            # systemone candidate softmax temps
ANVIL_S1_HEAD=file.head                     # trained scorer for systemone candidates
ANVIL_BIND=127.0.0.1                        # bind loopback-only (default 0.0.0.0)
COLIBRI_THREADS=8                           # saturates ~8 on the reference box
COLIBRI_NOBATCH=1                           # disable batched prefill
