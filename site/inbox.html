How it fits an integrator's stack

1 · Plug the mailbox

A small connector reads maildir / mbox / IMAP and posts each message to /v1/route. Output: sorted folders plus a decisions.jsonl audit trail — who was routed where, at what confidence.

2 · Train the client's head

Export a few hundred labeled mails from the client's archive, train a head in under an hour on CPU. The trunk never changes — the head file is the client's, portable, versionable.

3 · Let it abstain

Below the confidence threshold the mail lands in a review queue instead of the wrong folder. Wrong-folder mail costs more than unsorted mail — the engine is built to know the difference.

Why not just prompt an LLM?

Cost shape

An LLM call per mail is a meter running forever. This is a 7.8MB appliance on a VM — the hundredth mailbox costs the same as the first.

Calibrated no

A prompt improvises a label. This returns a typed decision with a confidence trained against a holdout — abstention is a first-class output, not a hope.

Data stays

Client mail never transits a third-party API. For an integrator selling to cautious SMEs, that's the whole sales conversation.
